論文内の図や表についての説明を作成する際に各手順で LLM に対して送信するプロンプトの例です．

### 手順2のプロンプト例
原稿内で利用している図表の元データについて説明を作成したいです．
図表がどのようなデータから，どのように作成されたのか，元データがいつから存在していたのかを示します．
目的としては，以下の3つがあります．
1. 利用した図表の元データに関する説明を作成することで，図表の作成方法を記録する
2. 原稿内で利用している図表を作成できるか確かめる際にどのようなデータ，コマンドを使えばいいのか確認できるようにする
3. 元データがいつから存在していたのか，ということを問い合わせられた際の証明として利用する

まずは，添付した原稿内も挿入されている図表を探してください．
図表について，作成に利用したファイルをコメントで指定しているため，検索して示してください．

### 手順3のプロンプト例
それぞれの図表作成用ファイルの内容を確認することで， 図表の元となるデータを推測してください．

### 手順4のプロンプト例
それぞれの図表の元データについて，以下の順序で動作を実行してください．

 1. まず，それぞれの元データをからハッシュを作成してください．
 　 この操作には，create_hash というTool を利用できます．
 2. 次に，ハッシュ値を用いて証跡のログファイルを検索することで，そのデータがいつから存在していたか確かめてください．
 　 この操作には，search_target_from_log というToolを利用できます．
 3. 2で取得したデータが存在していた日付について，そのデータ取得日の証跡ログを作成してください．
 　 この操作には，create_daily_log_file というToolを利用できます．
 　 また，ログのファイル名はdaily_hashlog_検索した日付.logの形式にしてください．
 4. 3で作成したログファイルからハッシュを求めて，日時ハッシュを作成してください．
 　 この操作には，create_hash というTool を利用できます．

最後にここまでの情報を元に，それぞれの元データについて以下の情報を示してください．
 1. 元データファイルのハッシュ値
 2. 元データはいつから存在していたか
 4. データ取得日の証跡ログのファイル名
 3. 存在していた日に関する日次ハッシュ
